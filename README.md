# 🍲 Iya Adam Kitchen — Online Ordering System

Full-featured food ordering web app with real-time chat, order tracking, admin dashboard, and menu management.

## 🚀 Features
- Beautiful food menu with images
- Shopping cart & checkout

- Real-time chat between customer and kitchen
- Customer comments/reviews
- Admin dashboard (add/edit/delete menu, manage orders, reset menu)
- Live updates via Socket.io
- Data persistence (data.json)
